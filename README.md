# Landing page Paggluten

Reconstrução estática responsiva baseada no screenshot fornecido.

## Executar

Abra `index.html` no navegador. Para evitar restrições de arquivos locais em alguns navegadores, também é possível iniciar um servidor estático dentro desta pasta:

```powershell
python -m http.server 4173
```

Em seguida, acesse `http://localhost:4173`.

## Edição

- `index.html`: textos, seções, CTAs e estrutura.
- `styles.css`: cores, tipografia, espaçamentos e responsividade.
- `assets/`: recortes visuais extraídos do screenshot de referência.
